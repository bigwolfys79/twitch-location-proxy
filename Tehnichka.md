# Tehnichka — как создать свой воркер за 10 минут

Расширение не работает без твоего личного Cloudflare Worker. Бесплатного
тарифа хватает с огромным запасом: 100 000 запросов в день, а через воркер идут только
крошечные служебные запросы (токен + usher), **видеотрафик через него не ходит
вообще** — сегменты качаются напрямую.

Свой воркер = свой лимит, свои логи, никакой зависимости от чужой инфраструктуры.

---

## Шаг 1. Аккаунт Cloudflare

1. Зайди на [dash.cloudflare.com/sign-up](https://dash.cloudflare.com/sign-up)
2. Зарегистрируйся (email + пароль, подтверждение по почте)
3. Тариф выбирать не надо — бесплатного (Free) достаточно

## Шаг 2. Создание воркера

1. В левом меню: **Compute (Workers) → Workers & Pages**
2. Кнопка **Create application / Create** → **Create Worker**
3. Имя: любое, например `twitch-location-proxy` → **Deploy**
4. После деплоя нажми **Edit code** (редактор кода)

## Шаг 3. Код воркера

1. Открой файл **`worker.js`** из этой папки, выдели всё (Ctrl+A), скопируй
2. В редакторе Cloudflare: удали всё (Ctrl+A → Delete), вставь скопированное
3. Нажми **Deploy** (справа сверху)

Пока ничего работать не будет — не хватает одной привязки (следующий шаг).

## Шаг 4. Привязка Durable Object (⚠️ самый важный шаг)

DO — это «жилой» кусок воркера, который физически исполняется в Европе
(Германия/Франция/Нидерланды). Именно поэтому Twitch видит разрешённый регион
и отдаёт 1440p. Без этой привязки стрим играет, но 2K не появится.

1. Открой свой воркер → **Settings → Bindings (Привязки)**
2. **Add binding → Durable Object Namespace**
3. Заполни:
   - **Class name:** `USRelay` *(точно так, с большой буквы)*
   - **Namespace:** создай новый, имя `US_RELAY`
4. Сохрани. Если спросит про SQLite-миграцию — соглашайся

## Шаг 5. Проверка

Открой в браузере `https://<имя-твоего-воркера>.<твой-субдомен>.workers.dev/`

Должно ответить: `Twitch Location Proxy is Running! (weur relay)`

## Шаг 6. Подключение к расширению

1. Клик по иконке расширения **Twitch Location Proxy** в панели браузера
2. Вставь адрес своего воркера: `https://имя.субдомен.workers.dev`
3. **Сохранить** → открой стрим → в меню качества появится 1440p60 2k

## Путь для продвинутых: через wrangler (всё в одной команде)

Если не хочешь кликать в дашборде — деплой вместе с привязкой DO одной командой:

1. Установи [Node.js](https://nodejs.org)
2. В папке проекта открой терминал и залогинься:
   ```
   npx wrangler login        # откроет браузер, нажми Allow
   ```
3. В `wrangler.toml` поменяй `name` на своё имя воркера
4. Деплой (создаст и привязку, и миграцию автоматически):
   ```
   npx wrangler deploy
   ```

## Требования, без которых 2K не появится

| Требование | Почему |
|---|---|
| **Логин в Twitch** | анонимам Twitch держит капу `AUTHZ_NOT_LOGGED_IN` |
| **HEVC-кодек в системе** (Windows: Store-пакет «HEVC Video Extensions» или корпоративный ISO-пак) | 1440p-исходник стримеров обычно в HEVC; Firefox декодирует через системный кодек. Проверка: в консоли страницы `MediaSource.isTypeSupported('video/mp4; codecs="hvc1.1.6.L150.90"')` → `true` |
| **`media.hevc.enabled = true`** в `about:config` | Firefox-переключатель HEVC |
| **GPU с аппаратным HEVC** | Intel 6-го поколения+, NVIDIA 950+, AMD RX 400+ — у современных карт есть |

Каналы, чей 1440p-исходник вещается в **AV1**, работают без HEVC-кодека
(AV1 Firefox декодирует всегда).

## Диагностика, если что-то не так

| Симптом | Причина / что смотреть |
|---|---|
| Ошибка #2000, стрим не грузится | Воркер не отвечает или привязки нет: проверь Шаг 5, что `/` отвечает |
| Стрим играет, 2K серый, плашка «Ограничение по местоположению» | Токен создан мимо воркера: проверь адрес в попапе; логи `npx wrangler tail <имя> --format json` — там должен быть POST на `/proxy?url=https%3A%2F%2Fgql.twitch.tv...` |
| Плашка «Вы вышли из системы» | Токен ушёл без логина: перелогинься в Twitch, обнови страницу |
| 2K серый, плашка «Проблема с устройством» | Кодек: HEVC-канал без HEVC-кодека в системе — см. таблицу требований. AV1-каналы работают |
| В логах 403 на `playlist.ttvnw.net` | Не должно случаться: плейлисты ходят напрямую. Обнови расширение |

Логи воркера в реальном времени:
```
npx wrangler tail <имя-воркера> --format json
```

## Частые вопросы

**Это безопасно? Что видит мой воркер?**
Через воркер проходят только служебные запросы (токен + usher) и твой
Twitch-авторизационный заголовок при запросе токена. Он нужен, чтобы Twitch
считал тебя залогиненным. Логи кода их не сохраняют. Видеотрафик и чат — мимо.

**Почему нельзя один воркер на всех?**
Бесплатный лимит — 100 000 запросов/день на воркер, и DO исполняется
последовательно (очереди при толпе). Свой воркер = свой лимит и никакие очереди.

**Почему воркер в Европе, а не в США?**
Список разрешённых для 2K регионов: США, Канада, Западная Европа и др.
`locationHint: "weur"` даёт Германию/Францию/Нидерланды — в белом списке.
Хочешь США — поменяй в `worker.js` `"weur"` на `"enam"`.

**Сколько стоит?**
0 ₽. Free-тарифа хватает на личное использование с многократным запасом.
